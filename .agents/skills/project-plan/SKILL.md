# Project plan
Read root/local AGENTS, current source/tests, and only relevant stable docs. Record current behavior, locked scope, acceptance criteria, affected seams, risks, tests, and truly blocking decisions. For multi-session work create only `state.md`, `progress.md`, and `implementation-plan.md` under `docs/ai/work/<feature>/` unless a phase genuinely needs independent detail. Stop instead of inventing architecture/product/security/schema decisions. Planning does not authorize implementation or GitHub writes.
