# AI context system

This directory stores resumable project state, not chat transcripts.

- `CURRENT_STATE.md`: short repository checkpoint and active PR relationships.
- `WORKFLOW.md`: shared Claude -> ChatGPT/Codex -> Gemini quality flow.
- `work/<feature>/state.md`: exact resume point for genuinely multi-session work.
- `work/<feature>/progress.md`: compact status.
- `work/<feature>/implementation-plan.md`: scoped slices and exit criteria.

Create per-phase files only when a phase needs substantial independent detail.
